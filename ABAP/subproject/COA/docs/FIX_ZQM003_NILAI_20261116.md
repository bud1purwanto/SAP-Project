# Fix ZQM003: Value = nilai print ZQM002 (16 Nov 2026)

Perintah user (16 Nov): "bisa kamu balikkan dulu yang alias tadi terus patch yang pembenaran zqm003 dulu?"

## 1. Masalah

ZQM003 (include `ZQMI_COA_ALV`, FORM `RPT_BUILD`) menghitung ulang rata-rata dari `IT_MIC1` setelah membuang nilai kembar:
`DELETE ADJACENT DUPLICATES FROM LT_UNIQUE COMPARING VBELN MATNR MIC MICMIT`.
Kalau dua lot berbeda punya nilai yang sama, nilai itu hanya dihitung sekali. ZQM002 merata-rata per inspection lot (dedup INSLOT + grup JR `GET_AVG_KEY`), jadi angkanya bisa berbeda dengan COA yang dicetak.

- Logika ini sudah ada paling lambat **19 Sep 2026** (backup repo), jadi bukan efek patch alias.
- Komentar F01 *"Simpan hasil final agar ZQM003 memakai nilai yg sama dgn ZQM002"* menunjukkan maksud desainnya sama. Laporan TRST-AISYAH: dulu sudah pernah diminta, tapi yang diperbaiki hanya ZQM002.
