Berikut hasil impact analysis dari sisi ABAP terkait rencana perubahan perhitungan Expired Date / Best Used roll. Detail lengkap ada di Excel terlampir.

Kesimpulan utama: dampaknya luas, terutama di report dan label. Expired Date roll tidak disimpan di SAP. Setiap report dan program label menghitung sendiri dengan rumus yang sama, yaitu Production Date (GR 101) + ZZEXPIREDLIVE (hari). Jadi aturan baru tidak cukup diubah di satu tempat.

Program yang menampilkan Expired Date: 34 program (hasil scan seluruh source Z/Y di SAP, lalu dicek satu per satu apakah benar menampilkan Expired Date):

AreaJumlah programDi mana terlihat
Label roll10Program label dipilih otomatis sesuai label type batch (tabel ZMAP_LABEL), antara lain label standar, Windows (A010-A013, A161, CP18), DOCX (A153-A159, B101, C109, D128, E127/128/133), Inchi, A132, A400, A401, dan label Toyobo (ZTYB03). Juga T-code ganti label ZLABEL90 dan ZLABEL91.
Label HU / pallet9Output HU (Z001/Z002), label pallet ZHU020, ZHU021, ZHU023, ZHU025, dan label HU per label type (A146, A400, A401, Windows).

Total34Report berlaku di semua company (Trias, TTA, TTE, UNS). Label type khusus TTA (TA02-TA07) dan TTE (TE02) tidak mencetak Expired Date.

Label roll tidak punya T-code sendiri. Label tercetak otomatis setelah transaksi produksi (misalnya slitting) atau saat cetak ulang, dan isi labelnya ditentukan oleh label type, bukan oleh transaksinya.

Catatan penting:

  • 7 dari 34 program (antara lain ZQM001P, ZEQM001P, ZBMBC2, label HU ZHU021/023/025) menghitung tanggal produksi sendiri tanpa FM standar, sehingga tidak terlihat dari where-used biasa dan harus diubah satu per satu.
  • Sudah dicek langsung di SAP DEV dengan contoh DO 0085006287 (GR 23.11.2026, umur 180 hari): ZBMBC, ZBMBC2, ZSD012N, ZSD024 dan ZQM001P semuanya menampilkan 22.05.2027. Dengan aturan usulan, best used di label menjadi Juni 2027. Screenshot ada di Excel.
  • Umur simpan tidak seragam: Trias mayoritas 180 hari, sedangkan TTA dan TTE mayoritas 365 hari. Aturan "+6 bulan" perlu dipastikan berlaku untuk company mana saja.
  • Selain itu ada 6 program label (antara lain A131, A136, A138, A139, label PMI, label HU KT&G) yang mencetak tanggal/bulan produksi, bukan expired. Program ini ikut terdampak kalau bulan produksi di label juga digeser sesuai usulan.
  • Sejalan dengan info Mas Cahya, OLAP mengambil Expired Date langsung dari report SAP (ZBMBC, ZSD024). Jadi kalau report SAP diubah, OLAP ikut berubah setelah data diturunkan ulang.

Dampak per opsi:

  • Hanya label diubah: tetap 19 program label (roll + HU/pallet) yang harus diubah. Tetapi 15 report tetap menampilkan tanggal lama, sehingga label fisik (Juni) dan SAP (Mei) berbeda di QA packing, monitoring stok, monitor DO, dan COA.
  • Label dan SAP diselaraskan: 34 program diubah. Saran kami dibuat satu function module pusat "Expired Date" yang dipanggil semua report dan label, supaya hasilnya sama di semua tempat dan perubahan berikutnya cukup di satu titik.

Hal yang perlu diputuskan di meeting dengan user:

  1. Kriteria customer kritis (STT dll.) dan pengecualian metallized CPP: berdasarkan customer, type film, label type, atau setting di SO/quotation?
  2. Company yang ikut: Trias saja, atau juga TTA, TTE, UNS?
  3. Tanggal persis di report SAP: awal bulan, akhir bulan, atau tanggal produksi? (label hanya bulan, report menampilkan tanggal penuh)
  4. Umur simpan tetap hari (180/365) atau diganti bulan (6/12)?
  5. Tanggal mulai berlaku, dan apakah roll lama ikut dihitung ulang. Karena tidak disimpan, perubahan rumus otomatis mengubah tampilan roll lama di report.

Catatan: analisis ini berdasarkan SAP DEV. Pengecekan di PRD menyusul bila diperlukan.
